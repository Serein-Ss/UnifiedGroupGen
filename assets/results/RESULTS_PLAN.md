## 3. 完成核心论文需要什么结果

建议把贡献收敛为：“从群和轨道规则构造合法状态及合法更新，以一套共享连续模型学习空间群与层群材料，并支持性质或部分结构条件。”数学统一构造、共享生成实证和条件可控性分别给出证据。

| 核心问题／论文主张 | 必须交付的结果 | 当前状态 | 优先级 |
|---|---|---|---|
| 编译器确实构造正确的合法自由度 | 明确假设下的推导；轨道约束残差、基底秩、晶格正定性、编码—展开误差与采样轨迹误差 | 已有推导和局部测试，需整理为覆盖范围明确的数值表 | P0 |

| 学到了材料分布，而非仅满足规则 | 合法随机先验与训练模型对照；有效性、唯一性、新颖性、分布覆盖 | MP20已有初筛、去重及训练匹配；MPTS52和联合模型未补齐，缺先验对照 | P1 |

## 4. 评价口径：每一个“有效”都要明确指什么

| 指标层次 | 定义与分母 | 要保留的补充信息 |
|---|---|---|
| 输出成功率 | 成功输出结构数／全部生成尝试数 | 描述失败、数值失败、导出失败、超时分别计数 |
| 目标群包含 | 目标操作在给定容差下保持结构，允许实际群更高 | 最大群操作残差；容差；晶胞设置 |
| 精确群匹配 | 识别群与目标群在一致设置下等价 | 升高对称性、降对称性、识别失败分开；LG需原生层群识别 |
| 代数合法性 | 晶格群相容、轨道关系及已施加观测约束满足 | 最大／中位残差，正定性，非有限值，积分步数 |
| 几何有效性 | 无重合、无非有限值、距离满足声明的绝对和元素相关阈值 | 原子半径来源、半径比阈值、2D自周期邻居和高度处理 |
| 化学筛查 | 按明确规则检查元素组合、电荷平衡等 | 规则不适用材料单列，不能将筛查通过当成物理证明 |
| 唯一性 | 同一次生成集合中结构去重后的占比 | 结构匹配容差、是否先筛有效；另报告相对所有尝试的唯一有效产出 |
| 新颖性 | 相对实际训练集合未匹配的结构占比 | 不能只对测试集查重；跨MP20／MPTS52来源共同排查 |
| 性质命中 | 独立评估值落入预先给定容差的比例 | 全尝试分母为主；可评估有效样本上的条件命中率另报；未知不当命中 |
| 稳定性 | 统一能量参考下凸包能／相对能量；必要的声子核验 | ML估计与DFT分列；热力学、动力学和可合成性分开 |
| 成本 | 总成本／有效且满足任务的候选数 | 生成时间、模型调用数、识别、弛豫成本分别记录 |

二维材料不能用真空大小决定体密度或每原子体积的“好坏”。C2DB采用面内面积／原子、层厚与面外坐标分布；3D体积／原子与2D面积／原子分图。以带真空的三维空间群识别代替层群识别，也不能直接证明层群目标命中。

对于条件生成，建议同时记录“原始生成结构”和“统一弛豫后的结构”的性质及对称性。解除保对称限制的弛豫可以揭示破缺目标群的趋势；只有保对称弛豫会漏掉这类不稳定通道。

## 6. 机制实验与推荐规模

本节数值均为建议的实验计划，当前结果仍只有每组64个样本。

### 6.1 必要机制对照

1. **规则先验→训练模型：** 对相同描述分别生成，检查合法性相同条件下几何、化学筛查和结构分布是否改善。这直接检验学习器的价值。
2. **共享→独立：** 在一致划分下分别训练3D和2D模型，与共享模型比较各来源质量，记录训练暴露与参数／计算预算。共享权重有效并不要求每项指标都优于独立模型；若声称迁移收益，必须由对应指标支持。
3. **连续后端→完整链路：** 固定描述评价后端，再开放Transformer评价端到端，区分描述选取失败与几何生成失败。
4. **性质条件与CFG：** 固定评估目标、组成可选；比较CFG=0与若干非零强度，联合报告性质命中、有效性和多样性。训练分布中的不同性质目标至少覆盖低、中、高三个档位。
5. **可组合观测：** 若正文突出该能力，选择固定面内晶格、固定部分独立坐标两类任务，报告观测误差和剩余自由度上的质量，避免全部参数固定导致任务退化。

对物理加权归约与欧氏归约、不同损失归一化的消融，在论文把这些细节列为贡献时开展。群平均和零空间投影在选定表示／度量下可能等价，先判断代数关系；等价实现适合比较效率与数值误差，不能据此宣称表达能力不同。

### 6.2 计划采样与统计

| 阶段 | 建议数量 | 目的 |
|---|---|---|
| 现有联合best的初步评价 | 每来源、每模式256次；3来源×2模式=1,536次 | 确认真实SG/LG输出、碰撞、层厚和来源分布；不用于宣布最终排名 |
| 正式无条件生成 | 每来源、每方法至少1,000次 | 主结果有效性／覆盖／新颖性；匹配最终所选基线协议时统一调整 |
| 性质条件生成 | 每来源、每目标档位至少200次，低／中／高目标 | 比较目标响应、命中率及多样性；多性质联合任务单列 |
| 训练随机性 | 主方法及关键独立／共享对照建议3个训练种子 | 报告训练重复之间的均值和离散程度 |
| 物理核验 | 数量按资源和主张预先确定，记录候选选择规则 | 避免只挑成功案例；失败和不可评估都保留 |

样本增加不能替代训练种子重复。比例使用二项置信区间，按来源分表；有重复描述时进行按描述聚类的bootstrap作为补充。原始生成统计、筛后统计、弛豫后统计保留各自分母。

固定描述重建任务可选择独立测试集的分层子集，统一每描述候选数K并报告Match@K与结构匹配容差；K不是增加训练数据的手段。真实描述包含额外先验，应与仅给组成的CSP指标分表。

## 7. 增强实验：不作为当前主线的启动条件

| 扩展 | 能回答的问题 | 当前处理 |
|---|---|---|
| 未见轨道组合、未见群—轨道配对、整个群留出 | 规则组合外推与学习迁移 | 等现有联合模型结果完成后决定；跨所有来源统一留出 |
| 规则内容条件编码器 | 操作内容能否改善未见规则生成 | 尚未实现；不能写入现有检查点能力 |
| 平面群生成 | 同一接口在(d,p)=(2,2)的实例化 | 已有目录支持不等于已有训练结果；若保留广泛实证主张再补数据 |
| 扩散模型后端 | 理论接口是否独立于生成过程 | 可作为方法扩展，无需当前同时训练 |
| 共线磁矩、磁空间群、自旋群 | 内部自由度表示的扩展 | 当前论文讨论方向，暂不要求数据与性能表 |
| 全面速度优化与大量容量消融 | 性能成本和扩展性 | 先取得质量结果；报告基础成本即可，未声称加速就无需围绕速度扩展主线 |

未见组合在数学上可以合法展开，不能保证低能或符合材料分布。轨道类型有限，但同类型轨道实例可重复；未限定原子数和轨道数时，组合不是可穷尽的有限清单。因此覆盖表必须注明原子数／轨道数上限与合法性规则。
