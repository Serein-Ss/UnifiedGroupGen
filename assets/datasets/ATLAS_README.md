## 08：TiO₂ / MoS₂ 的群与轨道示例

![TiO2 and MoS2](08_tio2_mos2_symmetry.png)

参考 SGEquiDiff Figure 1 的“结构—Wyckoff—自由度”组织方式，绘制项目的真实编码示例：MP20 `mp-2657` 与 C2DB `1MoS2-1`。图像由确定性展开得到，没有用生成模型或图片生成模型构造原子位置。

- TiO₂：空间群 136，Ti 2a 固定位置和 O 4f 一维轨道，`z=(k1,k2,u)`；标准胞 6 原子。
- MoS₂：层群 78，Mo 1a 固定位置和 S 2f 面外一维轨道，`z=(k1,h)`；独立胞 3 原子。
- TiO₂ 的坐标是分数坐标；MoS₂ 的 x/y 是分数坐标，h 是 Å。
- 绿色箭头表示对独立位置参数求导得到的允许变化方向，统一放大便于观察，不代表真实运动速度或训练轨迹。
- 边界显示可能包含周期像；MoS₂ 重复为面内 2×2，不沿法向重复。

**图的作用：**说明三维和二维材料可共享“规则＋独立参数”的表示；两个示例本身不能证明对所有群的普遍性。

## 09：完整空间群与层群分布

![Symmetry distributions](09_group_distribution.png)

参考 SLayerGen Figure 6 的全编号柱状图、分区和直接标注方式。MP20 / MPTS52 使用 SG 1–230，C2DB 使用 LG 1–80；柱高为该来源中结构记录的百分比，所有群都保留，未出现的群高度为 0。

**图的作用：**展示数据对称性覆盖与频率不均衡，说明测试时需要同时报告整体结果和群分层结果。不能把 SG 和 LG 的同一个数字看作同一个群。

## 11：化学体系复杂度与晶胞原子数

![Chemistry and cell sizes](11_chemistry_cell_size.png)

每行一个数据集，每列分别为不同元素种类数、来源晶胞原子数、标准化晶胞原子数。柱高为记录百分比，虚线为中位数，横轴保留完整范围。

化学体系复杂度在本图中定义为不同元素的数量：1 为单质、2 为二元、3 为三元，以此类推，不是轨道数或原子数。MP20 的“20”限制来源胞原子数；常规标准胞经过对称性标准化可能超过 20。

**图的作用：**区分化学复杂度、系统规模与晶胞约定，避免误读标准胞扩展为数据错误。

## 12：性质标签的统计分布

![Property distributions](12_property_distributions.png)

参考 CrystalFlow 的性质直方图组织方式。展示当前预处理数据保存的形成能、带隙和凸包能，共 3×3 个面板；横轴为完整范围，纵轴为有限标签在每个 bin 中的百分比，共 60 个等宽 bin，标出中位数、有限标签数与零值比例。

- MPTS52 当前预处理记录没有带隙标签，面板明确显示缺失。
- C2DB 的带隙标签仅部分存在；缺失不补零。
- 能量单位为 eV/atom，带隙为 eV。
- 数据集间的能量参考、计算流程不同，图描述各自标签分布，不宣称数值可无条件互换。
- 本图不是生成性质的评估结果，也不使用性质预测器重新计算标签。

**图的作用：**说明哪些性质具备训练监督、条件目标处于分布中的什么位置，以及缺失和长尾情况。

## 13：Wyckoff 轨道坐标自由度

![Wyckoff dimensions](13_wyckoff_dimensions.png)

参考 SGEquiDiff Figure 1 的自由度统计。柱高为“至少含一个 d 维轨道的结构数 / 该数据集结构数”。同一结构可能含多种自由度，所以四个柱的比例不要求相加为 100%。轨道实例计数另外保存在 `tables/wyckoff_dimension_counts.csv`。

**图的作用：**显示固定位置与可动位置的组成，解释只统计总生成有效率时，可能有大量不需要连续坐标生成的样本。

## 14：每个数据集随机 20 个真实结构

| 数据集 | 20 结构总览 | 单图目录 | 随机种子 |
|---|---|---|---:|
| MP20 | [总览](14_random_structures_mp_20.png) | `structures/mp_20/` | 20261018 |
| MPTS52 | [总览](14_random_structures_mpts_52.png) | `structures/mpts_52/` | 20261019 |
| C2DB | [总览](14_random_structures_c2db_51.png) | `structures/c2db_51/` | 20261020 |

参考 DiffCSP Figure 12 的结构阵列布局。使用 NumPy 随机生成器，在每个数据集全部参考划分的记录中均匀无放回抽取 20 条，不按美观程度、群或原子数过滤。各图顶部标出简化化学式，下方标出样本 ID、SG/LG 和独立胞原子数。来源与确切 descriptor/state 保存于 `tables/random_structure_examples.json`。

这些是真实数据示例，不是模型生成结果。MPTS52 / MP20 之间没有跨数据集排重。样本图单独适配视窗，无共用物理长度尺，不能通过球在图中的像素大小比较晶格尺度。

结构样式沿用项目已确认的 Crystal Toolkit 风格：哑光元素球、双色接触棍、半透明配位多面体、细晶胞边框和 RGB 方向标。显示接触来自既有渲染器的距离规则，不是化学有效性的认证。

二维图采用 2×2 面内显示，只画面内晶胞基面，不画三维周期盒。为便于观察，将所有原子沿法向共同平移，使基面位于最低原子下方 1 Å；不改变原子间距离、独立状态或数据文件。该显示基面不表示面外周期，也不用于计算体积或密度。

## 重现

在项目 Python 环境、具备原预处理 JSONL 和现有统计表时执行：

```bash
python assets/datasets/source/build_dataset_atlas.py --seed 20261018
```

输出 71 个 PNG：8 张统计/示例图、3 张二十结构总览和 60 张结构单图。源代码只写入图集、派生统计和清单，不训练模型、不修改数据、不运行结构优化。

论文参考图的原始来源已记录在 `assets/literature/dataset_figures/sources.json`。本图集使用自己的数据与渲染结果，参考其图形组织，不复制原论文的数据或结构。
