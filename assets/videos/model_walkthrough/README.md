## 如何解读

1. **训练过程演示**由当前权重重放训练机制，加上真实历史损失曲线组成。并未保存或恢复全部198轮中的原子轨迹、隐藏特征与优化器更新录像。训练连接路径与采样ODE是两个不同对象，分别标注。
2. 特征色图直接来自实际激活，采用共享的对称对数色标，以显示不同量级。部分深层节点特征非常接近，这是本次探针的观察，不能仅凭两例就断言过平滑或模型失效，也没有为了画面效果替换它们。
3. 速度箭头将模型的混合坐标候选转换为笛卡尔量；合法速度通过晶格诱导度量的加权最小二乘得到。画面中箭头比例固定，分数坐标越过周期边界时可能跳到胞另一侧。
4. 每条Heun轨迹记录65个真实积分状态。视频在相邻状态之间对独立变量z做视觉插值，并经确定性展开绘图；插值帧不代表额外网络求值。为便于看清几何变化，结构视图逐帧自适应缩放，实际晶格变化应结合数值z和CIF读取。
5. 260个积分状态均核查了群操作、切向作用与晶格相容性；视频实际完整解码3168帧，核对分辨率、帧率和时长，抽取编码后的画面检查。数值见 `data/verification.json`。
6. 四个例子是机制展示，不能代替统计评估；距离阈值和目标群识别不证明化学有效性、稳定性、性质命中率或材料新颖性。

## 本地重建

在项目已有的Python≥3.10训练环境中，只需另外安装视频编码依赖，不必重装PyTorch：

```powershell
python -m pip install imageio-ffmpeg pillow
$env:MKL_THREADING_LAYER='SEQUENTIAL'
$env:OMP_NUM_THREADS='4'
$env:MKL_NUM_THREADS='4'
python scripts/build_model_walkthrough.py --stage all
```

默认路径对应本次下载后的本地检查点和服务器日志归档。可用 `--checkpoint <path> --history <path>` 指定其他位置。渲染使用Windows微软雅黑字体 `C:/Windows/Fonts/msyh.ttc`。现有数值轨迹可单独渲染，无需读取权重或重新训练：

```powershell
python scripts/build_model_walkthrough.py --stage render
python scripts/build_model_walkthrough.py --stage verify
```

`data/model_trace.json`保留实际输入、模型配置、随机种子、源代码哈希、编译基底、真实token概率、全部特征、速度、梯度、历史日志和四条积分轨迹。`data/video_manifest.json`记录章节与文件哈希。
