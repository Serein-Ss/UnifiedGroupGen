## 回归中补齐的执行兼容性

1. 已安装包的源码身份使用包内路径标签，不再假设代码位于数据工作目录中。
2. 旧配置/审计的输入位置通过统一解析器映射，内容哈希仍严格核验；未改写旧审计通过标志。
3. Python子进程可通过已安装工作流模块启动，不依赖checkout中的脚本副本。
4. CPU旧评估入口不再改写调用进程的CUDA_VISIBLE_DEVICES；子评估进程仍使用原CPU限制。
5. 编译常量缓存显式在非inference模式分配，避免先推理后训练时反向传播失败。常量值、
   模型结构、群约束、损失与采样公式保持一致；新增回归覆盖该切换，并复核真实检查点输出。
6. 新冻结源码采用包目录，历史冻结目录仍按存在的原路径读取；没有重写历史源码快照。

代码安装既支持项目根目录，也支持只复制unifiedgroupgen目录后独立安装。
