日期：2026-10-17。本文档是当前代码对应的论文证据清单。新图仅输出 PNG；实验生成文件放在 artifacts，论文图片及其数据表放在 assets。

## 2026-10-20 比较范围与必补训练对照

当前三套完整生成模型均为多性质联合CFG训练模型M。先使用现有M检查点比较结构分布与质量；M无性质条件采样必须如实标注，不能写成纯无条件训练基线。MP20、MPTS52历史单来源M与共享M的划分／预算不同，暂作描述性结果，不归因于共享学习。

正式论文必须补充U（训练时不提供目标性质）与S_j（每个性质j分别训练的单性质CFG模型），并与M在同结构记录、同划分、同预算下对照。先比较三类的无性质条件分支，再比较同一目标j的条件采样，最后评价M的联合目标。保持对称性构造与组成／观测策略一致，记录标签覆盖、条件可见模式及实际参数量。现有M整组丢弃不等于充分训练所有性质子集；若改变该策略需另设消融。

新增必补表：按U／S_j／M分别列结构质量、群／组成／自由度分布、COV、VUN、2D连通性及独立性质命中；单种子观察不作统计显著性结论。完整协议见总文章第10.5.1节。本轮只更新比较口径与计划，不启动新训练。

## 1. 文章要回答的一个问题

**在不同群和轨道规则产生不同合法自由度时，能否通过同一个构造接口，把这些状态交给同一组网络权重学习和生成？**

论文的因果顺序为：规则决定合法自由度 → 编译器构造合法状态与更新 → 共享模型学习不同规则下的材料分布 → 性质条件控制有效候选的分布。

目前主张范围应写成：空间群三维晶体与层群二维材料的统一构造及共享生成。平面群已有目录数值检查，尚无真实平面群训练任务；磁群、自旋群、超空间群、任意 d/p 群作用属于后续扩展。现有网络仍包含群编号与轨道类别编码，不能把未实现的“规则内容条件”写成已经验证的零样本泛化。

群论分类、核空间投影、正定矩阵对数各自并不是新的数学发现。需要突出并验证的是它们共同形成的、可执行的合法状态和切向更新接口，以及同一连续网络对 SG/LG 的实际适用性。是否具有独立于近邻工作的首创性仍需单独核对近邻方法，不能由测试通过推导。

### 理论中必须写出的边界

- 固定规则 a 的常规分支才有固定状态维数；所有分支的并集通常是分层空间，不是一个固定维数的全局光滑流形。
- 对称性保证的是包含指定群操作。严格等于目标群还受更高对称性、轨道退化及容差识别影响，另行统计。
- 独立参数 B 是局部/提升坐标图的线性基底；周期边界、原点选择及原子置换使表示一般不具有全局唯一性。
- log-SPD 晶格构造在已定义的相容参考度量、坐标约定和群作用下保证合法性。二维法向高度不是第三个周期晶格自由度。
- 零空间是约束的允许变化方向；它不代表能量、化学或性质约束自动满足。仿射观测 Az=b 与软性质条件 y 的保证不同。
- 编译器确定不同长度的 z 和展开图；共享网络处理展开的节点、边及规则特征，然后按对应基底归约速度。同一权重不要求所有样本 z 长度相同。

## 3. 主文每张图应是什么

### 图1：一套规则编译接口和一组共享权重

**位置：Method 开头。目的：让读者看懂统一对象和算法。**

- a：目标性质/可选组成 → 描述Transformer → 群、轨道实例及轨道元素。
- b：同一编译接口的两支实例：MP20真实TiO₂（SG136）与C2DB真实MoS₂（LG78）。显示周期方向、群操作、每个轨道的自由度和完整原子展开。
- c：a → (H0, 晶格不变基底, b, B) → z=(k,q) → Φa(z)。标明二维非周期高度与三维分数坐标的区别。
- d：合法随机先验 → 合法训练路径 → 共享OrbitFlow → 合法速度/积分 → 结构。性质CFG和固定晶格观测分别画在正确位置。
- 图中将“数学保证”标在展开/合法更新，将“学习目标”标在分布与性质上。

**可支持的结论：** 3D和2D通过同一状态接口、同一连续网络完成生成。图本身不能证明生成质量或优于其他模型。

**已有：** assets/paper/fig01_unified_method.png 与 fig01_material_examples.png；后者从真实数据状态确定性展开，提供可复现的数值坐标图。编译、共享OrbitFlow、Heun循环及TiO₂/MoS₂独立自由度已核对，投稿排版可再按模板调整。

### 图2：统一表示确实覆盖所声称的数据与规则

**位置：Experiments 第一个结果。对应“数据能否统一表示”。**

- a：三个来源的记录数、覆盖群数和编码成功率；明确分母是源记录而非独立材料总数。
- b：晶格、坐标与总自由度分布，以及压缩比例；SG/LG并列显示，不把层高度算为周期晶格变量。
- c：编码—展开—再编码误差、群操作残差、合法路径残差；给中位数、P95、最大值和失败数。对数轴中的零要标明显示下限。
- d：位置基底秩与稳定子约束核维数一致性；SG230/1731轨道类型、LG80/477、PG17/72的目录检查。
- e（可移补充）：原始CIF重新标准化/编码与已有状态的吻合，以及标准化对原结构产生的变化。

**当前真实结果：** 102610/102610份已准备记录的代数检查通过；2280个单轨道类型目录检查通过；原始来源重编码仅做了每来源16条，即48/48。前两项不等于原始CIF已经全量重编码，也不等于枚举了无限可重复的轨道实例列表。

**需要补齐：** 正式服务器全量源重编码；理想化位移/度量变化的完整记录与未知数。不要把缺失的3D原始理想化字段填成0。

**可支持的结论：** 在给定表、标准胞约定、容差和当前数据范围内，统一编码/展开与合法切向构造数值一致。不能据此声称任意群作用、任意材料均已验证。

**输出：** assets/representation/representation.png、summary.json、records.csv.gz、catalog.csv、source_reencoding.csv。详细数据分布图已有 assets/datasets。

### 图3：一个检查点能否生成三来源的3D/2D材料

**位置：Experiments 的共享生成主结果。**

- a：MP20、MPTS52、C2DB分别报告几何、SMACT、联合有效、目标群精确回收；显示全部尝试分母和未知数。
- b：COV-P/R、有效且唯一且未匹配训练集的产率（VUN）；每个重复采样种子显示为独立点。
- c：按群、自由度分层的有效率及样本数，防止零坐标自由度结构主导整体成绩。
- d（可移补充）：3D密度/体积，2D面积每原子/厚度，以及元素数分布与各自测试集的距离。
- 对照至少包含共享模型和同划分分来源模型。外部CGDiT/CrystalFlow等基线只有在数据、任务输入和预算对齐后才能写进公平比较。

**正式预算：** 起步每来源4096次无条件尝试；若三个来源都做即12288次。若每来源、每种模式、三个种子都做4096次，六模式合计73728次。不要把4096次成功输出写成4096次总尝试。正式与历史64次结果分开。

**可支持的结论：** 同一权重在三来源有可测的结构分布学习能力；相对单来源模型的质量、参数与训练预算代价可量化。只有共享模型三来源生成都完成后，才有共享生成实证。

**不理想时如何解释：** 某一来源明显退化说明共享表示可用，但当前共享学习存在负迁移；不能隐藏该来源或仅报平均分。

**代码/PNG：** evaluate_joint.py + evaluate_generation.py；build_paper_results.py 输出 03_shared_generation_validity.png、03_shared_generation_coverage.png、03_shared_generation_by_dof.png。

### 图4：连续生成机制带来了什么

**位置：共享结果之后，解释机制。**

- a：固定同一批TRAIN描述、元素和采样种子，比较合法随机先验与训练后的连续流；群合法率可能都很高，关键看几何、化学、分布和多样性差异。
- b：在相同描述下加入固定晶格观测，报告自由坐标生成质量和观测最大残差 |Az-b|。
- c：每个描述实例分别报告，而不仅把所有实例池化；说明选取了多少群和非零坐标自由度实例。
- d（可选）：组成约束、固定部分q、采样步数变化。现有CLI支持前两类，正式实验需补充与性质条件不同的成功定义。

**可支持的结论：** 编译保证合法性，连续学习进一步改变材料质量；仿射观测与基础对称约束可兼容。观测残差小不等于条件分布采样已经正确。

**本次已补代码：** controls任务准备、--prior、固定晶格采样残差、配对定义/输入哈希。输出 04_continuous_controls.png、04_observation_residuals.png。

**还需重新训练的机制消融：** 无观测训练、无性质条件训练，或替换晶格/轨道表示等改变训练分布/网络的消融。关闭CFG不等于训练过一个独立无条件模型；本次未伪造这些模型权重。删除切向投影后采样不是当前算法的可靠消融，可能离开合法空间，需要另行定义和训练。

### 图5：性质条件是否真正有效

**位置：应用结果；保留“逆向设计”标题时是必需证据。**

- a：用TRAIN标签P10/P50/P90定义单性质目标，避免用测试分布选有利目标；重复数值只保留一次。
- b：相同种子下CFG=0/1/2。横轴目标值，纵轴独立性质计算的中位数/IQR，加入y=x参考线。
- c：有效性质命中数/全部尝试，与联合有效率、多样性和目标误差同时报告。
- d：多性质目标的可行性与联合命中率。当前脚本默认一次变化一个性质；额外联合目标需明确设置并检查标签共同覆盖，不随意拼凑三个来源的能量。

**当前模型是否支持：** 已训练的联合检查点含性质编码与CFG；不是只有无条件模型。当前仍缺独立性质评估，因此“输入了目标”不能作为“达到了目标”的证据。MPTS52无带隙标签时不能评价该域的带隙条件设计。

**可支持的结论：** 同一模型可在所测试的目标范围控制独立测得的性质，并量化有效候选产率。如果目标与独立预测不随动、或命中率只在极低有效率下提高，应报告限制。

**代码/PNG：** conditions campaign + 独立CSV/ASE计算器桥接 + evaluate_generation.py；输出 05_condition_response.png、05_condition_valid_yield.png。没有独立值时这些图列为待完成，不输出伪曲线。

### 图6：生成候选的物理意义（若文章声称稳定材料发现则必须）

- a：全部尝试 → 几何化学筛选 → 统一预算弛豫 → 凸包能筛选 → 弛豫后唯一/新颖的候选数量；同时显示未计算与失败数。
- b：弛豫前后几何和群变化；群降低并不自动表示生成时群约束失效，可能是材料物理不稳定或无约束弛豫。
- c：2–4个真实候选的结构、来源、目标/独立性质、能量和结构匹配证据。
- d（材料发现主张需要）：选定代表候选的DFT与声子。没有虚频筛查不等于可合成，低凸包能不等于动力学稳定。

**可支持的结论：** 指定独立计算器和能量参考下的候选筛选收益；DFT/声子证据达到什么层级就写什么层级。训练集新颖性不等于对所有材料数据库新颖；当前SUN接口中的N是对指定训练参考的匹配结果。

**代码/PNG：** assess_structures.py 负责结构任务导出、调用本地ASE计算器、3D可选晶胞弛豫/2D固定面内胞弛豫、兼容元素参考下的形成能/相图凸包；evaluate_generation.py 计算弛豫后匹配与SUN。输出 06_physical_screening.png。计算器、权重、DFT任务、合法参考相集和声子任务仍需研究者提供。
