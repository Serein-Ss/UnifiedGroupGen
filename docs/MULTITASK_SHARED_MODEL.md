# 三项主任务、一个共享模型的联合训练方案

2026-11-12。三项任务同等列为主任务：无目标性质的从头生成、目标性质条件生成、指定组分CSP。当前用户选择先独立训练每项任务，使用独立检查点。本文件保留后续混合训练对照设计，不是当前默认；硬任务状态、余额路径、经验先验及独立训练已实现，见[INDEPENDENT_TASKS.md](INDEPENDENT_TASKS.md)。

## 1 输入约定

性质通道只接收目标性质及可见掩码。空间维度、周期秩、群操作、轨道模板属于硬规范；群按结构类型的TRAIN频率外部采样，不训练群分类头。

化学硬任务有三种模式：free、allowed_set、fixed_counts。allowed_set仅要求非空输出结构的所有元素均属于给定集合，允许任何非空子集、单元素及任意合法计量，不要求集合内每种元素出现。fixed_counts给定每胞元素整数计数，参照FlowMM的基本CSP输入；只给约化式需额外指定或枚举每胞化学式单元数Z。

内部任务状态包括：化学模式、允许元素掩码、是否知道精确计数、目标计数、当前已分配计数、余额和可更新变量掩码。这些是网络可见的硬任务状态，不放进性质编码器；它们在统计上仍会影响结构分布。源数据集ID不作为新模型的性质条件。

## 2 网络最小调整

| 部分 | 保留或增加 |
|---|---|
| 主干 | 保留同一个JointAtomGraph完整原子图、操作编码、约束层与解码 |
| 硬任务编码 | 新增化学模式／允许集合／精确计数可见性／目标与余额编码，汇入全局token；避免把未知计数与数值零混淆 |
| 原子／轨道 | 继续读取当前元素与几何，显式知道该轨道已有元素及其计数贡献 |
| 性质编码 | 只编码真实可用的目标性质和可见掩码；无性质任务用不可见标记 |
| 连续输出 | 共用公共晶格、当前原子坐标锚点；CSP不需要独立几何头 |
| 事件输出 | 共用完整动作评分头，在硬任务对应的合法支持上归一化；CSP出生动作同时指定模板与元素 |
| 时钟 | 共用剩余事件估计，当前count_head不是原子数预测头 |

不需要三个主干、三个任务检查点或先训练独立骨架Transformer。不同任务可以有不同先验和合法核；共享权重不要求路径完全相同。网络必须读取硬任务状态，否则相同空图无法分辨“自由选择元素”和“必须最终填满指定计数”。

## 3 统一采用空图＋余额的CSP路径

为了复用现有空图及变维事件主线，选用终点精确计数、过程逐步分配的CSP路径。完整元素库存从一开始就已知；当前原子图可以尚未包含所有原子。此处中间N可变，终点N和每元素总数必须与输入一致。这与FlowMM全程固定N的内部路径不同，但符合其给定完整组成、输出几何的CSP任务。

初始化从指定计数和随机公共晶格开始，原子图为空，余额等于目标计数。CSP不自由预测元素总量，只学习给哪个合法轨道分配何种已有元素及如何生成几何。

CSP动作使用明确元素的整轨道birth／split，扣除相应重数；delete返回该轨道的元素计数；element或replace先退回旧计数再扣新计数；swap按实际重数计算净变化，不假设异重数守恒。CSP不使用没有计数归属的MASK出生。任何动作后余额均非负，当前计数与余额之和恒等于目标。

仅余额非负还不充分：动作后需保留一个在剩余预算内可完成的轨道分配见证，检查重数、剩余零维位置、容量和事件预算。可缓存有界整数可行性求解结果；优先采用保守的可完成见证，不宣称枚举所有轨道编辑路径。训练和推理使用完全相同的判据。余额全零、结构非空、无MASK时才能END；预算耗尽或不可行明确失败，不改计量、不强行END。

连续锚点、随机出生坐标与原子迁移仍用同一类公共状态桥。事件的目的核可以依硬任务变化，但只能依当前可见任务状态与事件，不能偷用真实终点坐标。隐藏特征事件后重新计算。

若后续需要与FlowMM全程固定N的路径做消融，可另设固定元素多重集、守恒轨道重排的路径，但它不是目前推荐的默认路线；不能一边声称固定N一边调用非守恒单独birth/delete。

## 4 三种训练视图一起进入同一次训练

同一真实结构可产生：A，无目标性质、计量未知的从头生成视图；B，性质可见、计量未知的性质生成视图；C，每胞计数可见、性质不可见的基准CSP视图。组合性质与CSP可后续评估，不替代三项基本任务。

有属性标签的记录生成B视图，缺失标签不填零；所有受支持记录可生成A/C。采用混合任务批次或按批次交替更新同一模型、同一优化器。初始可用三项等权的任务采样作为实验起点，并单列有标签样本覆盖；这不是宣称最优比例。批量资源和任务梯度尺度需分别监控。

allowed_set是A/B下可用的硬规范：训练时从包含真实元素的允许集合抽样，并随机加入其他TRAIN支持元素，避免让模型误学“允许集合中的元素必须全部出现”。单元素结构本身来自真实训练记录，不能伪造未出现的子集结构作为标签。仅限制元素集合不固定原子数或计量。

A/B沿用自由计量程序，但按实际允许集合生成合法元素动作。C重新构造余额受限的教师程序，不能直接复用现有会插入任意错误元素和临时轨道的增强。最基本C程序按目标轨道随机顺序生成，并联合指定已知元素；每个前缀的剩余真实轨道给出一个可完成见证。纠错增强只插入余额、固定位置与预算均可恢复的动作，并核对同一推理支持。

从合法随机初态出发，使用同一目的核、排序事件时刻和连续桥模拟到随机时间。终点和未来程序只用于监督，模型只读当前状态、性质可见值和任务硬输入。C的真实计数是允许的输入；C的真实群、轨道和坐标不是推理输入。

## 5 一套权重的损失与引导

每个任务仍监督公共晶格／坐标锚点，以及剩余事件数加权的完整动作和时钟。总体目标是三类任务损失的明确加权平均；每个任务内部保留剩余数权重，不能换成未加权动作分类。

性质任务直接通过性质可见的去噪／事件学习条件分布，不必另设一个性质预测器或把目标值当回归输出。性质dropout只改变性质可见性；不能同时丢掉CSP计数或允许元素掩码。后续若做CFG，必须保持相同硬支持，离散率非负；不能直接套有符号的率外推。

共同参数不保证三任务自动互相促进，需要分别检查梯度与质量，防止负迁移。验证分别报告三任务，按预先规定的联合准则选择同一个检查点，不能为三个任务各挑一个最优权重后宣称一套权重统一。

## 6 群初始化与CSP基准

普通生成按类型内TRAIN频率采群。固定计数CSP先确定每胞组成／Z，并在具有轨道计数可行解的群中重归一化同一经验频率；这是可行支持过滤，不是训练组分到群概率头。可行性不保证相稳定或所需多晶型被覆盖。测试中不得读取真实群或Wyckoff配置；若另测真实对称信息输入，单列更强输入任务。

FlowMM的基本CSP协议给定每胞元素与N；测试结构坐标仅用于匹配，不用于采样。优先在MP-20复现输入、划分、晶胞约定和匹配设置，再加C2DB-51的层群版本。当前工程含修复数据及常规胞展开，未经核对不能称与原论文数值可直接对比。

[FlowMM附录A.2](https://arxiv.org/html/2406.04713v1)采用StructureMatcher的stol=0.5、angle_tol=10、ltol=0.3，报告匹配率及仅匹配样本上的归一化几何误差，归一化尺度为(V/N)的立方根；论文明确未做同组成的多样本统计。因此先报告基本Match@1，额外Match@5/20明确为扩展协议，不归于FlowMM原报告。

C2DB层材料不直接沿用含任意真空的三维体积归一化；需单独给出面内匹配、法向高度、平移／真空处理及尺寸归一化。所有失败留在分母，组分精确性与匹配率分开报告；基态预测还需候选弛豫与能量排序。

## 8 已核实的基线事实

[FlowMM官方实现](https://github.com/facebookresearch/flowmm)分别给出model=null_params的CSP训练与model=abits_params的从头生成训练；[正式论文](https://proceedings.mlr.press/v235/miller24a.html)明确为一对任务模型。其方法统一不等于同一套训练权重。

[DiffCSP官方实现](https://github.com/jiaor17/DiffCSP)也分别给出基础CSP与diffusion_w_type从头生成训练命令。这些是代表性设置，不意味着全部现有工作必须分开训练；本项目拟议的单权重多任务训练需要直接验证，不能仅以“一个网络”作为已证实的新颖性结论。
