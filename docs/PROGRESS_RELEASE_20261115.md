# 进度展示与阶段计时发布

本次发布包含进度展示、阶段计时、逐步日志，以及这些模块依赖的核心目录重构和旧路径兼容入口。新方案位于 `pl_modules/unified`，原两阶段方案位于 `pl_modules/two_stage`；模型参数注册和旧检查点读取接口保持兼容。

交互训练终端保留 Epoch、Train 两行，验证期间临时显示第三行 Validate。训练和验证各自显示自己的 loss、连续几何、元素和轨道跳转分项；Epoch 汇总显示整轮均值、最佳验证值和早停计数。训练时钟在验证期间冻结，速度和 ETA 只使用本阶段有效时间。JSONL 逐步记录支持非交互运行，Slurm 输出保留简洁轮次摘要。

本次不发布独立的严格 `.env` 校验变更，配置路径保持前一版本的兼容行为。网页、论文草稿和本机环境文件不属于此次发布；数据、权重和训练结果不加入本次提交。
