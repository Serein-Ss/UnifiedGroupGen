# UnifiedGroupGen：完整论文架构与研究计划

日期：2026-10-04。文档性质：方法设计与实验计划；实现进度见 VALIDATION.md。没有正式基准结果，因此不填写虚构提升幅度、稳定结构数量或计算成本优势。

## 题目与摘要草案

**Property-Conditioned Material Generation through Unified Group–Orbit Constraints**

材料结构逆向设计需要同时搜索离散对称性描述和连续几何自由度。已有方法已通过空间群等变更新、Wyckoff 参数化和层群扩展实现部分严格约束生成。本工作研究一个构造性的群—轨道接口，将周期秩、空间操作、轨道实例和内部表示编译为合法结构参数化、随机先验、训练路径及切向更新。性质条件 Transformer 提出群、轨道和元素；流匹配网络在相容正定晶格与轨道自由坐标中生成几何。框架支持空间群、层群和平面群，并允许在固定描述下加入仿射结构观测。共线单位磁矩作为表示扩展进行算法验证。拟通过 MP20、MPTS52 和 C2DB 比较群约束、离散条件提议、双阶段性质条件及二维/三维共享参数的作用，并区分代数合法性、几何有效性、性质命中和弛豫后稳定性。

## 1. Introduction

### 1.1 研究意义

材料结构生成同时面对元素组合、原子数、晶格和多原子几何的高维搜索。群操作约束把重复原子运动联系起来：模型可以把容量用于独立轨道的自由度，而不是重复学习完整晶胞中的所有坐标关系。对称性还为带隙、磁有序及其他物性提供结构性条件，但对称性本身不能确定这些物性。

二维材料不是具有很大 c 轴的普通三维晶体：其平移秩为二，层外高度是非周期变量。若把真空厚度和 z 的周期噪声当作真实自由度，模型可能学习到与材料几何无关的导出约定。以周期秩和表示为接口处理二维与三维，能够明确共享部分和不同部分。

### 1.2 已解决和仍待研究的问题

已有工作已经实现 Wyckoff 自由度生成、空间群等变扩散/流匹配、层群生成、离散 Wyckoff 描述以及性质条件控制。因此本工作不能将“在 Wyckoff 切空间生成”或“空间群扩散改为流匹配”作为首次贡献。

可研究的差异是：同一构造接口能否同时给出参数化、合法先验、合法路径、物理度量投影和共同观测条件；性质条件能否实质改变离散描述提议并提高同预算命中率；二维/三维共享模型是否在低数据情形下具有优势。这些是需要实验回答的问题。

### 1.3 贡献候选

1. **构造接口**：从群、周期秩、轨道及内部表示生成 Phi_a、切向投影、随机先验与合法训练路径，并给出正则点条件下的正确性与自由度覆盖分析。
2. **性质条件的两阶段逆向设计**：模型内部学习性质到群/轨道/元素的分布，再进行性质条件几何流，不在推理时从经验群分布抽样。
3. **共同约束条件生成**：基础群约束与固定晶格、部分结构观测进入同一合法自由度系统，训练和采样共用观测纤维。
4. **跨周期秩验证**：空间群、层群和平面限制共享构造，主实验针对三维与二维结构；磁性仅证明表示扩展的可操作性。

这些是拟检验贡献，不是当前已证实的论文结论。

### 创新性判断

基础群作用、稳定子、核空间、Reynolds 平均和不变正定矩阵的对数/指数构造属于既有数学。框架的潜在方法贡献应落在**可执行构造、共同观测纤维以及可验证的跨任务一致性**。仅把三个群类型包装进一个类，或给现有几何模型增加 Transformer，不足以形成强理论贡献。

如果主实验显示优势仅来自前端更多参数、更好的数据或更多弛豫预算，则不能把结果归因于统一理论。应使用相同后端和相同预算拆分原因。

## 3. Preliminaries

| 符号 | 定义 |
|---|---|
| d, p | 嵌入维数和周期平移秩 |
| G, R_g, t_g | 群和分数表示中的仿射操作 |
| W=(w_1,...,w_K) | 可重复的独立轨道实例列表 |
| Z_alpha | 轨道元素，展开到该轨道全部原子 |
| L, H=L^T L | 列向量晶格与正定度量 |
| k, q, z=(k,q) | 相容对数晶格参数与真实轨道自由坐标 |
| Phi_a | 从合法参数到完整结构的展开 |
| C_a, Pi_a | 坐标约束矩阵和合法速度投影 |
| y, c | 统计性质条件与硬结构/组成条件 |
| M_a | 固定离散规则下的合法结构空间 |

群不变的概率密度与每个样本满足固定群是不同要求。这里核心保证为样本级操作闭合；裸网络的任意世界坐标旋转等变性不由此自动成立。

固定 a 不意味着所有样本原子数相同。元素由轨道生成；同一轨道内一致。轨道类型可重复，零维已占位置不可重复。轨道退化后重数和局部自由度可能变化，需要另行处理。

## 4. Method

### 4.1 问题定义与联合分布

未知规则的逆向设计：输入材料类型、可选组成和性质 y，生成 a、Z、L、F。

\[
p(a,Z,x\mid c,y)=p_\phi(a,Z\mid c,y)p_\theta(x\mid a,Z,c,y).
\]

固定描述的补全：输入 a 与部分连续观测 c，生成其合法纤维内的结构。此任务不能与使用真值 a 的“全新结构生成”混报。

### 4.2 构造群约束接口

输入已有操作表与 Wyckoff 元数据，输出：

\[
a\longmapsto(\Phi_a,\Pi_a,p_0,\text{合法路径},\text{自由度/验证器}).
\]

晶格通过不变正定度量指数参数化构造；坐标通过独立仿射轨道参数展开。详细推导和命题见 THEORY.md。

这一接口是“统一”的具体含义：公共输入对象与相同构造流程适用于不同平移秩；不是重新枚举所有空间/磁性/自旋群，也不是将所有材料空间压成一个线性零空间。

### 4.3 描述 Transformer

自回归生成 G、W、Z 和 STOP。群 token 同时包含类型与编号。轨道 token 对应已有表中位置；元素使用原子序数类别。性质向量进入每个 token，组成计数作为另一条件。

合法性包括重数与元素计数、最大原子数、轨道预算、零维位置单占及剩余组成可完成性。前缀搜索保证最终符号约束，不能保证低能或合理价态。当前没有显式预测一个可能与轨道列表矛盾的独立 N；N 由展开重数求和决定。

当前研究实现是有序 AR 模型；等价轨道实例排列、原点和晶胞规范仍可能产生重复描述。后续应比较确定排序、实例排列增强和排列不变集合模型。不要把 token 去重当作结构去重。

### 4.4 连续几何网络

参考 CGDiT/newton 与 CrystalFlow 的消息传递基础，使用一个共享 CSPNet 风格网络处理完整展开的晶胞：元素/轨道/群嵌入、时间嵌入、性质嵌入、晶格度量、周期平面特征及非周期高度差。

坐标头提出全原子候选速度，通过物理度量最小二乘收回真实轨道参数速度。晶格头输出对称矩阵，再投到不变基底。零维轨道没有坐标输出自由度，但仍参与消息传递影响其他轨道与晶格。

基础实现使用全连接 N² 消息图、逐结构计算并累积 mini-batch 梯度，以便先核查方法。大规模稀疏图、GPU 批处理和吞吐优化不是当前理论实验的先决贡献。

### 4.5 合法先验与流匹配

随机自由参数展开为合法结构。周期 q 在单位区间，层高度为实数；k 使用高斯先验。只在独立参数选择周期路径；位置展开包含 t，速度展开不含 t。

FM 损失包含 k 均方误差和展开到物理坐标后的速度误差。采样使用参数域 Heun 积分再展开。参数化让每一步群关系与晶格正定性成立，ODE 步数仍影响生成精度。

不同群/W 分支具有不同维数，共享网络通过参数化元数据适配。连续路径不增删轨道；若需要动态变维应追加离散转移。

### 4.6 性质编码与 CFG

配置支持 scalar 与 categorical；连续缩放仅由训练集计算。缺失标签进入可学习空嵌入。训练按样本丢弃全部性质以训练 CFG 空分支；组成和硬结构观测保留。

前端混合 logits，后端混合同一合法空间的速度。除条件强度消融外，应比较只前端条件、只后端条件、两者同时条件以及完全无性质条件。

### 4.7 共同结构约束

固定描述下，完整坐标线性观测代入仿射轨道映射，得到自由参数的共同核空间。固定晶格通过固定 k 实现。当前代码实现提升坐标图内 A_obs z=b_obs 的随机先验投影、训练端点检查、速度投影和数值回缩。

一般非线性观测的 Jacobian 切向公式可写出，但需要另行实现约束先验与积分；不能将条件性质模型当作严格等值面采样。

### 4.8 共线单位磁矩扩展

群表示约束 C_epsilon n=0 与单位轴约束结合。只测试明确给定表示、置换与正负号下的合法采样，不开展大规模磁性材料发现，也不与 AFM 稳定性模型混淆。

### 4.9 理论证明目标

1. 操作展开正确，包括非对称型分数平移。
2. 正则轨道参数覆盖完整合法局部坐标切空间。
3. 晶格不变 SPD 参数化的合法性与完备性。
4. 合法先验、路径和参数积分的样本级群约束。
5. 相容仿射观测的共同纤维与切向速度。
6. 前缀完成搜索的符号合法性；明确其与精确条件概率采样的差异。

这些证明主要是既有数学在具体生成对象中的构造与适用条件，不应包装为全新的群论定理。

## 5. Training Strategy

### 数据

- MP20：三维主数据，FE/BG 条件；保留原 split。
- MPTS52：更大结构与元素/轨道复杂性检验，FE/凸包能条件。
- C2DB：层群主数据，gap/hform/ehull；先完成源坐标约定审计。
- 平面群：合成与二维限制算法验证，没有另行假造材料数据库。

原始标量命名通过显式映射统一；不能因名称一致就假设不同数据库的 DFT 泛函和能量参考一致。无条件几何可以先做跨数据训练；联合条件物性训练需要额外计算域/标签保真度条件。

### 训练阶段

| 阶段 | 工作 | 必须通过的检查 |
|---|---|---|
| S0 | 群表、轨道、晶格、周期秩编译 | 群闭合、CA=0、核维数、SPD 与度量不变性 |
| S1 | 描述模型 CE | 数据端点合法、组成准确完成、无空结构 |
| S2 | 连续 FM | 合法训练路径、有限损失/梯度、端点展开一致 |
| S3 | 两阶段性质条件 | 空/条件分支同 a；训练集 scalers，无标签泄漏 |
| S4 | 部分观测 | 条件先验合法、端点相容、全轨迹观测残差 |
| S5 | 共线单位磁矩工具 | 表示约束、单位长度、无解情形明确失败 |

当前训练入口可共同优化两模型：CE+FM，总损失权重先为 1；无需穿过离散采样作不可微的端到端梯度。后续可以分阶段预训练及分别设损失权重，是否必要应由实际诊断决定。

训练与验证以数据标识检查重叠，并保存内容哈希。正式泛化分析还必须增加结构去重与原型级划分，ID 不重复不代表结构不重复。

### 数据预筛与后验评估

描述掩码排除符号非法组合；生成后检查距离、重数、实际 SG、MLIP 弛豫和物性；通过筛选后再作 DFT/声子验证。所有失败、重试和弛豫计入成本。当前没有实现外部 MLIP/DFT 调用，因此不能宣称已减少稳定性验证成本。

## 6. Experiments：要开展的实验

### E1：算法正确性

验证全部群表晶格及真实自由度；选一般、镜面、轴、零维位点与非对称型群检查 ker C 与轨道参数像空间相等；测试六方物理度量、层高度非周期、固定观测及磁性表示。保存残差与数值容差。

### E2：无性质条件生成

MP20 主表；MPTS52 扩展；C2DB 层群表。评估描述完成率、几何有效率、实际群一致性、独特性、相对训练集新颖性、多样性及弛豫后表现。常规胞/原胞统一后再比较原子数统计。

### E3：描述提议来源

保持同一个连续后端，比较经验群/轨道抽样、无性质条件学习前端、性质条件学习前端、WyckoffTransformer/其他前端。避免把前端和后端同时改变后的提升归因于单个模块。

### E4：两阶段条件位置 2×2

| 前端性质 y | 后端性质 y | 研究问题 |
|---|---|---|
| 无 | 无 | 无条件基线 |
| 有 | 无 | 合适离散描述的贡献 |
| 无 | 有 | 描述内几何调控的贡献 |
| 有 | 有 | 二者是否互补 |

每种设定针对同一目标范围、相同候选总数和相同弛豫预算。目标不能由测试集结构真值导出其离散描述。

### E5：有无显式群约束

有群约束模型与标准全结构流使用相同消息网络容量、条件编码和采样步数。当前 newton 已有对称性处理，不能将其直接命名为“完全无对称性约束”。

### E6：固定结构观测

固定晶格、部分轨道参数、兼容的线性坐标组合。报告全轨迹残差、条件任务成功率和多样性。一般非线性观测是后续独立实验，不能预先填入当前结果。

### E7：共享二维/三维模型

统一权重与分开训练在总参数、总训练步数和数据预算匹配下比较；强调低数据二维性能及大结构成本。性质跨库混合前先加计算域条件。

### E8：共线单位磁矩扩展

只比较合法/非法表示输入、不同核维数和单位长度残差；不宣称预测磁基态或发现磁性材料。

### 基线层次

直接后端：SGFM、SGEquiDiff；跨周期秩：SLayerGen；结构参数化：DiffCSP++；一般晶体 FM：CrystalFlow；描述模块：WyckoffTransformer、WyckoffDiff/Adapter、DynaCrys；性质前置系统：CrysVCD；用户原模型：CGDiT/newton。

不能要求每种方法支持其未实现的任务。先做共同任务、同条件、同预算比较，然后单独列拓展功能表。对公式条件 CSP 与未知组成 DNG 分开报告。

### 指标与计算链

1. 描述：合法率、组成匹配、轨道重数、群覆盖、0D 占据、轨道实例数。
2. 代数：操作位置/速度残差、晶格不变性、路径残差、观测残差。
3. 几何：最小距离、原子重合、轨道退化、体积/面积、层厚度。
4. 物性：弛豫后目标误差、范围命中率、基于独立预测器/DFT 的一致性。
5. 稳定：统一参考凸包、能量、力收敛、弛豫后群保持；选代表样本再作 DFT 与声子。
6. 搜索：固定候选数和固定总成本两种比较，包括全部拒绝、重试和优化。

负形成能不是凸包稳定；限制对称性弛豫的局部极小不能证明抵抗破坏对称性的扰动。二维验证不能用真空超胞的 spglib SG 代替完整层群验证。

### 消融与统计

- 真实自由度 vs 每个代表三坐标；参数化 vs 完整坐标速度投影。
- 合法路径 vs 独立全原子 wrapping；物理度量 vs 分数欧氏度量。
- 学习群/轨道 vs 经验分布；完成前缀 vs 末端过滤。
- 前后条件位置；CFG 强度；先验；Heun 步数。
- 群 ID 特征 vs 操作/表示元数据；当前群 ID 网络不应被宣称具有群编号外推能力。

建议先做约 1,000 候选的开发诊断，再冻结配置做约 10,000 候选和至少三随机种子。数字是规划，不是已完成样本量。报告不确定性、失败原因分布及同样本选择规则下的外部计算验证。

## 7. Discussion：论文必须主动交代的问题

1. 统一接口的贡献与 SGEquiDiff/SGFM/SLayerGen/DynaCrys 的实质差异是什么？
2. 数据转换、常规胞扩大、轨道排序会不会改变任务难度和计数？
3. 低数据层群提升来自共享表示还是更多训练数据？
4. 条件前端是否减少无效结构，还是只把分布集中到容易稳定的二元/单质组成？
5. 所谓物性条件能否在未见范围/原型上泛化？
6. 参数化只能保证群包含，如何处理更高对称性和轨道退化？
7. 全连接图和前缀搜索的实际时间/内存瓶颈是什么？

## 8. 研究里程碑与停止条件

| 阶段 | 可审查产物 | 继续条件 |
|---|---|---|
| P0 | 理论、来源和代码接口 | 不把已有方法当作新发现；对象和边界清楚 |
| P1 | S0 数学测试和数据审计 | 全部群表晶格正确；主数据端点可重建；C2DB 源坐标约定确认 |
| P2 | 无条件 SG 基线 | 与同预算 CrystalFlow/SGFM 比较，至少生成/评价链完整 |
| P3 | 性质条件描述提议 | 同后端有可复现收益，不仅属性预测器内自我打分 |
| P4 | 仿射共同观测 | 全轨迹约束与生成多样性可检验 |
| P5 | 层群与共享模型 | 真层群数据与指标；明确数据域差异 |
| P6 | 正式论文与外部验证 | 核心主张都有比较、消融或数学证据 |

磁性不会成为阻塞普通材料主线的前置条件。若统一构造不能带来可验证的新能力或公平比较优势，应缩小论文主张为条件描述与共同观测生成，而不是维持“统一所有群”的宽泛标题。
