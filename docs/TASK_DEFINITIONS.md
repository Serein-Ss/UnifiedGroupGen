# 当前任务定义与默认输入约定

生效：2026-11-12，依据用户最新约定。本文件覆盖旧稿中“同一网络必须学习类型／群初始化”的目标；本轮已补齐独立任务训练与采样代码，联合训练为后续对照。

## 1 默认词汇

| 用词 | 本项目固定含义 |
|---|---|
| 条件生成 | 仅指目标性质条件生成，例如目标带隙、形成能等 |
| 无条件生成 | 不给目标性质，从简单随机先验从头生成元素、晶格、坐标及轨道配置 |
| 结构类型／对称规范 | 空间维度、周期秩、群操作、设置和模板；属于硬结构规范，不称为性质条件 |
| 群初始化 | 按结构类型统计TRAIN群频率，外部随机采样；不训练群概率头 |
| 化学体系限定 | 指定允许元素集合；允许非空任意子集和单元素，不要求全部出现 |
| 指定化学式的CSP | 指定元素计数或化学计量比后生成结构，组分属于任务硬输入 |
| 内部状态输入 | 当前元素、晶格、坐标、轨道及进度；读取状态不等于增加性质条件 |

项目术语不改变数学事实：指定组分后的结构分布在统计上仍是条件分布。硬约束保证输出计量，模型学习其中的结构偏好。群可作为分布的索引，但不设可学习选群概率。硬编码的是约束满足机制，不是把所有结构偏好写死，也不是对一个样本同时施加全部群。

## 2 优先级与经验群先验

三项并列主任务一起实现，但先独立训练：无目标性质从头生成、目标性质条件生成、指定组分CSP，各有权重与检查点；同权重联合训练后续测试。按类型统计TRAIN频率采群、查表／缓存得到操作和模板，再进入共享网络联合过程。不指定类型时，按声明的数据混合权重统计类型频率；指定类型属于运行模式选择。

频率只用TRAIN，固定识别容差、晶胞／原点设置和数据混合权重。零频群默认不采；群覆盖不等于训练质量。新增task_*检查点已保存TRAIN频率先验，可不指定群；旧无先验检查点仍要求显式spec，不增加神经选群头。

只有目标性质及可见掩码进入性质条件通道；不把群、Wyckoff标签、来源库或化学式放入该编码器。结构规范、词表和任务硬输入分开管理，网络仍需读取它们来计算合法变化。性质与群可能相关；固定经验先验下部分目标／群组合可能难实现，须记录失败，不暗中训练性质到群的分类器。

## 3 化学体系、化学式与晶胞大小

Li–Fe–O只限定元素范围，结构可以只有Li、Fe或O，也可以包含任意非空子集及任意合法计量，不要求三者全出现。约化式LiFeO2给出1:1:2比例；仍需指定或枚举每胞化学式单元数Z，得到Li1Fe1O2、Li2Fe2O4等整数计数。许多CSP基准直接给每胞完整原子类型列表和N，其输入信息多于约化式。

自由从头生成由模型生成计量；体系限定使用硬词表；固定计数CSP精确满足各元素计数，不用性质CFG或末端偏好代替。无性质目标的固定组分CSP是独立任务，不称为完全自由的从头生成。

## 4 独立训练、共享架构与CSP路径

三项任务复用同一主干／几何头／事件头的架构实现，当前各自训练和保存检查点，不混合任务。已加入任务硬状态编码，性质通道仍只读性质。指定体系仅限制允许集合，训练中使用包含真实元素的不同超集，不能误学为每种元素均需出现。

CSP默认沿用空图＋整轨道事件路径，给定完整计数并维护已分配量／余额。出生同时确定模板与已有元素，消耗库存；删除退回，元素／模板替换按净变化更新，动作后余额非负且保留可完成见证。余额归零才能END。中间原子数可以变化，终点精确满足给定N及组分，与FlowMM的CSP任务输入和终点契约一致，但内部路径不同。

组分可见不是只在最后过滤，而是训练时就给网络硬任务输入，并用与推理同样的受限程序及核模拟路径。指定计数不是泄漏；真实群、轨道、坐标不能在组分CSP推理时偷看。细节、损失与基准见[MULTITASK_SHARED_MODEL.md](MULTITASK_SHARED_MODEL.md)。独立版本已实现，使用与测试见[INDEPENDENT_TASKS.md](INDEPENDENT_TASKS.md)；同权重联合训练尚未启用。
