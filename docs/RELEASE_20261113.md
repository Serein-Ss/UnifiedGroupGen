# 2026-11-13：联合流、生成轨迹与训练效率更新

本次将现行周期 EquiformerV2 联合流、JointAtomGraph 对照、群操作约束、独立任务配置及测试整理进训练代码仓库。旧两阶段入口、检查点格式和已有输出保留。网页源码、论文草稿、权重、运行日志及本机临时验证产物不在本次新增上传范围内。

## 可以开始做什么

在 MP-20 和 C2DB-51 上分别启动无条件生成、指定组分 CSP 和性质任务的独立训练；性质任务仅使用实际存在的目标标签。无群输入使用 TRAIN 的经验群频率；限定元素集合允许只出现其子集；精确化学式使用受限路径。训练与生成支持现有按原子／边预算分批。从空图开始的生成可选保存完整中间轨迹，也可在批量生成中只记录指定的全局样本编号。

```powershell
python -m unifiedgroupgen.joint audit --experiment flow_mp20_dng
python -m unifiedgroupgen.run experiment=flow_mp20_dng runtime=joint_flow_fast device=cuda:0
```

C2DB-51 使用 `flow_c2db51_dng`；其他任务分别用对应 `csp`、`property` 选择器。精度和融合优化器只属于执行配置；正式运行和恢复时保持配置一致，不修改正在运行的训练。

## 本轮工程调整

- 周期邻居筛选向量化并缓存有限个平移网格；保持边顺序、自像和等距壳层。
- 可选 BF16、融合 AdamW 和较低日志频率；约束几何解码与切空间求解保持 FP32。
- 接通 EquiformerV2 原生核心激活重计算；默认关闭，保持原有参数名和等变核心。
- 验证真实 Lightning 训练中的梯度裁剪、检查点保存和恢复，而不只验证裸优化器步骤。
- 新 `flow_*_dng` 默认为纯无条件任务；历史 `task_*` 配置保留原值。
- 历史源码冻结在遍历文件前只解析一次根目录，避免重复 Windows 路径解析。

RTX 3060 上，4 条真实训练记录的隔离计算短测包含前向、反向、梯度裁剪和优化器更新：mp_20 的 BF16 融合模式从 0.6046 降到 0.5276 秒／步，峰值显存从 3048.1 降到 1974.7 MiB；c2db_51 从 0.2950 到 0.2940 秒／步，显存从 794.4 到 671.8 MiB。计时不含 CPU 教师路径、验证与磁盘 I/O，不能当作完整 epoch 加速率。激活重计算在本次短测中增加了耗时。
