# 评价术语、失败处理与完整测试集CSP

本次仅修订评价输出、采样导出检查和CSP计划，不更改模型架构、训练数据或训练目标，不启动正式任务。

## 固定名称和分母

|名称|定义|
|---|---|
|生成成功率|成功输出、可回读结构数 / 目标输出结构数|
|结构有效率|满足几何与化学判据的结构数 / 成功生成结构数|
|指定群准确率|群编号符合要求的结构数 / 成功生成结构数|
|有效结构产率|有效结构数 / 目标输出结构数，可由计数直接算出|
|性质命中率|独立评估达到目标的结构数 / 该目标请求的结构数|
|Match@K|前K个候选至少有一个匹配的测试案例数 / 全部测试案例数|

不再输出“已评价通过率”、`rate_on_evaluated` 或 `unknown`。
JSON比例字段为 `total,passed,failed,calculation_failed,rate,status`，计算失败计入failed，另保存原因。
没有运行该项检查，如没有独立Eh预测器，状态为 `not_evaluated`，不能把未做实验当作计算失败。
解析、有限值和指纹可计算性属于工程诊断，不作为模型效果亮点。

## 实际CIF问题

对本地 `baselines_256_local_seed142_20261026` 的5404个已存在CIF逐个复核：5382个回读成功，22个失败。
22个都出现近重合原子，原始原子表的最近距离均低于0.5 Å；解析器合并近重合位置，产生2/3/4/5等占位总和，超过允许的1。
例如C2DB组成任务sample_00070的最近距离约0.002196 Å。
这说明既有输出存在真实几何退化，同时旧采样存在“写完CIF就登记成功、没有立即回读”的工程缺口。
不能通过放宽占位率、删原子或归一化组成使这些结构冒充正常输出。

新增原生适配器会在导出前拒绝非有限状态、晶格和坐标，导出后回读并核对整数组成；失败记为生成失败。
完整旧文件不修改，失败样本保留。可用下面的只读命令复核：

```bash
python scripts/audit_cif_outputs.py --root <existing-results-directory> --output <audit-directory>
```

## 两套匹配参数

|显示名称|ltol|stol|angle_tol|3D scale|
|---|---:|---:|---:|---|
|Strict 严格参数|0.2|0.3|5°|False|
|DiffCSP 参数|0.3|0.5|10°|True|

来源：[DiffCSP官方RecEval/RecEvalBatch](https://github.com/jiaor17/DiffCSP/blob/main/scripts/compute_metrics.py#L109-L180)。
两套参数并列写入JSON、PNG图例和 `csp_metrics.csv`；CSV明确记录kind、三个容差及实际scale。
二维沿用层材料匹配，法向不取模、不按真空归一化，实际scale=False，并标为二维适配。

默认 `--csp-cases 0 --csp-k 20`：每个完整测试案例生成20候选，按原始生成顺序的前1、前5、前20个分别统计。
不是用20个中的最佳候选冒充Match@1，也不是从全部测试集中只抽256案例。
失败候选占据自己的序号。每个案例生成20个就足以形成三个可复现的嵌套预算，不需要重复生成1+5+20个。
所有测试参考组成用于仅组成CSP；固定描述诊断还额外给真实描述，二者分表。

## 部分结构补全

目标：固定已经给出的晶胞和部分原子，生成剩余原子，同时保持指定群约束。
现有 `Scaffold` 支持固定晶胞、指定群设置：完整已知轨道可作为描述前缀；不完整轨道需要完整描述及显式atom-map。
编译后把已知部分写成 `Az=b`，先将随机起点投到该约束，再将速度投到 `ker(A)`，积分后回缩保持约束。
这是硬约束采样，不对组成或片段做CFG；性质CFG可额外使用。
任意可变晶格与任意笛卡尔片段的联合约束未由此线性接口普遍解决，不能泛称全部片段条件已支持。
当前15套训练没有新增片段控制微调，补全质量需要另行评价。
