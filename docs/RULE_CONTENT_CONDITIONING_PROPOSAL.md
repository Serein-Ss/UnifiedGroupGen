# 操作内容与网络内部约束：现行联合模型契约

更新：2026-11-12。历史文件名保留以兼容链接。本文不再以“先固定描述、只给OrbitFlow增加规则特征并以未见群迁移为主线”定义当前工作。

现行目标是同一个晶体生成项目的单网络联合架构，完整数学定义见[THEORY.md](THEORY.md)。跨群迁移是可选研究问题，不是项目成立前提。

## 1 群编号与操作内容的关系

群编号是常规接口或初始化采样标签；实际约束由群操作及其作用设置给出。标准目录查表、缓存和操作自动编译共用同一规范接口。群编号、Wyckoff字母不能替代具体矩阵、周期方向与模板几何。

规范固定的是群作用和模板目录；当前占用列表、元素和公共几何在联合过程中更新。目标群属硬规范，未指定时按结构类型的TRAIN频率外部采样；不训练群头，新task_*入口已接入外部初始化。

## 2 网络中的显式约束

共享网络直接使用：

1. 全局操作编码、空间维度和周期掩码；
2. 原子之间的操作标记关系和当前轨道关系；
3. 注意力块之间的轨道标量协同及当前晶格下的笛卡尔切向向量场；
4. 合法事件集合及候选模板的重数、自由度、偏移、完整仿射基。

当前代码不将所有隐藏上下文都限制为不变标量，保留公共法向残差以表达教师锚点。类型化场满足对应约束；原始上下文／头不宣称整体严格等变。物理结构由当前模板和相容晶格硬解码保证操作关系。

## 3 化学、几何与轨道协同

元素事件以整轨道为单位，replace标记可同时指定新模板与新元素。当前几何和元素通过共享特征影响合法事件评分；事件改变配置后，重新编译坐标图和操作置换，重新计算原子图。

同一模板允许不同实例时，其自由坐标和元素可以不同；同一实例的伙伴必须协同。固定位置实例不重复占据。零自由度向量场为零不阻止元素事件，也不阻止合法配置切换。

## 4 与概率过程的共同契约

网络不只共享多个头。教师路径、完整目的核、事件强度、锚点监督和采样器使用同一状态定义。公共坐标残差不会被未说明地抹除；新增块、幸存块与异重数替换分别有固定对应规则。

改变合法集、出生分布、观测保持规则或采样温度都需要说明所学／所采路径的变化。所谓统一约束，不能只体现为最终输出的事后群识别。

## 5 不作新增贡献的通用组件

查表、群平均、核空间、SPD指数图、图注意力、共享主干、离散流匹配和生成器匹配均有既有基础。SPFlow、Orbitol、GEODE、SymmCD与SLayerGen分别覆盖重要近邻机制；比较见[REFERENCES.md](REFERENCES.md)和[RESEARCH_PLAN.md](RESEARCH_PLAN.md)。

当前关注的是可更新配置下的类型化约束、完整轨道事件和几何迁移构成的具体联合机制。尚未完成的群初始化、严格成分、动态观测和磁性训练不因文本更新被计为已有能力。

本项目“条件生成”只指目标性质。操作内容是约束机制，组分是CSP任务硬输入；约定见[TASK_DEFINITIONS.md](TASK_DEFINITIONS.md)。
