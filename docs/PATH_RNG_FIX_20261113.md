# 辅助路径预算回退与独立随机流修复

本补丁修复joint_flow_v2的训练辅助样本，不修改网络、损失、公共出生核、推理采样器或旧版sample_training_path。没有进行完整训练；旧检查点、输出、私有网页与论文草稿保留。

## 原因与修改

旧sample_path让程序构造、训练时刻、有序事件时钟和元素生命期共享一个NumPy状态，且预算回退会从同一种子重启整个函数。回退判定可依赖随后重新被用作时钟的随机数，破坏有序均匀时刻推导所需的条件分布。

现从根种子通过SeedSequence.spawn(6)派生固定编号的子流：

| 编号 | 用途 |
|---|---|
| 0 | 程序排列、编辑选择、临时锚点与辅助标签 |
| 1 | 训练时刻 |
| 2 | 结构事件时间 |
| 3 | 初始几何噪声 |
| 4 | 出生、split与替换核的随机创新 |
| 5 | 元素MASK生命周期 |

只有最终程序通过预算检查后才抽取其他随机量。回退仍可使用相同根种子重新选择无增强程序，但不会读取或复用参与判定的程序流作为时钟。出生坐标可依赖当前父轨道；独立的是现场随机创新，不是要求子轨道坐标与父轨道独立。

## 数学对应

在理想独立随机源假设下，给定最终程序P及其长度M，事件时间仍是M个独立Uniform(0,1)的顺序统计量。长度可依赖P，原始时钟随机流独立于P；不声称随机维数的时间向量与M无条件独立。

给定到t剩余R个事件，下一事件在(t,t+h]发生的概率为1-(1-h/(1-t))^R，故瞬时率为R/(1-t)。元素揭示时间为出生时刻到1之间的独立均匀数，当前MASK的风险率为1/(1-t)。原有remaining加权动作损失、元素交叉熵及几何桥因此仍与同一个辅助生成元对应。详细推导见[概率补充第37.1节](PROBABILITY_CLOSURE_20261113.md)。

SeedSequence解决随机状态隔离；数学结论仍把子流当作理想独立随机源。有限统计检查不能证明伪随机发生器的严格独立性或全部网络的良定性。

## 验证

新增test_joint_flow_path_rng.py覆盖预算回退、随机流非干扰、显式/随机训练时刻、可重复性、初态/出生流隔离、固定和随机程序长度、剩余事件风险率、MASK条件概率与物理端点恢复。

最终相关回归为573项通过、3项CPU BF16用例按既定规则跳过，其中新增随机流检查12项全部通过。其余覆盖两主干、三任务、周期图、约束层、轨迹记录和FP32/BF16训练恢复；源码安装包从实际Git暂存内容构建并通过归档校验。没有将修复前的565项历史计数重复累加。

12,000个种子的四事件路径诊断：首次事件早于0.2的理论概率为0.5904。修复前紧预算结果为0.6195；修复后为0.59258。修复后全部时钟均值0.50034、训练时刻均值0.50036。数字是有限统计证据，不是形式化证明或材料性能。

真实高轨道TRAIN记录各检查2,048个种子：MP-20的mp-550220有20个轨道，默认预算96未触发回退；C2DB-51的1Pd19Se32-1有51个轨道，触发6次。每次回退与同种子、无增强路径的时刻、完整轨迹及当前几何/元素状态逐项一致。这些记录的触发次数不是全数据集发生率估计。

短期集成使用原生周期EquiformerV2的小网络，在两库的DNG、性质、CSP任务上分别执行2个优化步，每项4条TRAIN、2条VAL，并从空图批量采样。全部尝试、未完成和数值失败均保留。最终计数与验证协议见[机器可读记录](validation/path_rng_fix_20261113.json)。

六项短训均按2步停止，验证损失有限，训练期间核心源文件未变化。主任务采样共12次，7次完成、5次在终端截断前未完成：MP-20的DNG与性质各0/2、CSP为2/2；C2DB-51的DNG为2/2、性质为1/2、CSP为2/2。采样仅8步、epsilon=0.01，完成表示算法状态完整，不表示物理稳定或性质命中；这些两步小网络结果不能作为材料生成性能。脚本另有批量计时尝试，与上述主任务12次分开记录，不混合分母。

短采样期间原生EquiformerV2报告过小于1e-4的边距诊断，流程未因此中断。本补丁未改变其诊断阈值，也未通过过滤尝试隐藏近重合结构；这种几何质量和数值风险仍需在后续模型训练及采样评估中检查。

修复前发布记录与r5审计保留为历史快照。当前修复不证明实际硬邻居图跨边界的正则性、有限网络的终端分布、长期收敛、全数据材料质量或性质/库存条件下的群混合正确性，也未新增磁性验证。
